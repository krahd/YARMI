# Playability notes

Add one short dated note after each real playing session. Record:

- what you tried;
- what felt musically useful;
- what obstructed playing;
- any unexpected possibility;
- whether the issue was semantic, interactional, DSP, timing, networking, or physical;
- the smallest change suggested by the observation.

The automated builds prove compilation, not playability. The first required session is one macOS
station and one physical iPad on the same local network, both with Link enabled.
